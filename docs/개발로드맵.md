# 다정다감 개발 로드맵 (Roadmap)

이 문서는 `요구사항정의서.md`를 기준으로, **한 번에 전부 만들지 않고** 단계별로 진행하기 위한 안내입니다.

## 현재 상태 (지금)

- Expo(React Native) + TypeScript 프로젝트 생성 완료
- 앱 표시 이름: **다정다감**
- 요구사항정의서(SRS) 문서 반영 완료
- **1-1 / 1-2 완료:** Expo Router 화면 이동 + 역할 선택(부모/도우미) 화면
- 실제 회원가입·예약·결제 기능은 **아직 없음** (다음 단계에서 시작)

## 절대 원칙

1. 미확정 사항(요금, 수수료율, 결제/환불 세부, 실시간 위치, 채팅 등)은 **임의로 정하지 않음**
2. 추가 유료 구독·유료 API는 사용 전 **비용 안내 후 진행**
3. 결제·자동화는 초기 테스트에서 수동 운영으로 대체 가능
4. **도우미 검증·인계·도착 안전 절차는 생략하지 않음**

---

## 1차 개발: 서비스 기본 구조 (다음 목표)

목표: 역할이 나뉜 앱 뼈대와, 화면으로 확인할 수 있는 기본 가입·등록 흐름

| 순서 | 작업 | 설명 | 관련 FR |
| --- | --- | --- | --- |
| 1-1 | 화면 이동(Navigation) 설정 | 부모 / 도우미 흐름으로 화면 전환 ✅ | FR-004 |
| 1-2 | 역할 선택·시작 화면 | P-01, H-01 ✅ | FR-004 |
| 1-3 | 회원가입·로그인 화면 | 처음에는 **로컬(가짜) 데이터**로 동작 확인 → 이후 무료 백엔드 연동 | FR-001~006 |
| 1-4 | 자녀 등록 화면 | 최소 정보만 수집 | FR-010~015 |
| 1-5 | 도우미 프로필·승인 상태 | 승인 전 지원 불가 원칙 반영 | FR-020~027, FR-023 |
| 1-6 | 예약 신청 화면 | 단건 중심부터 (정기는 2차) | FR-030, FR-032~035 |

### 1차에서 쓰는 기술 (비용)

| 항목 | 선택(안) | 비용 |
| --- | --- | --- |
| 앱 | Expo + Expo Go | 무료 |
| 화면 이동 | Expo Router | 무료 |
| 데이터(초기) | 앱 안 가짜 데이터(Mock Data) | 무료 |
| 데이터(이후) | 무료 티어 백엔드(예: Supabase Free) | 무료 한도 내 (연동 전에 다시 안내) |

> **지금은 Mock으로 먼저 화면과 흐름을 만들고**, 서버 연동은 별도 단계에서 비용·설정과 함께 진행합니다.

---

## 2차 개발: 핵심 매칭

- 도우미 지원 → 지원자 목록 → 부모 선택 → 예약 확정
- 단건 + 정기 예약
- **자동 배정 없음** (부모가 최종 선택)

## 3차 개발: 안전한 이동

- 지정 인계자 확인, 인계·이동·도착 상태
- 부모 알림, 긴급 신고
- 알림은 초기 수동/앱 내 알림부터, 푸시(Push)는 비용·설정 확인 후

## 4차 개발: 운영 및 수익화

- 결제·수수료·정산·관리자 페이지
- **결제 연동 전에 반드시 비용·수수료 정책 확정 필요**
