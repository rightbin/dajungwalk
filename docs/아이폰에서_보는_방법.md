# 아이폰에서 다정다감 보기 (앱 화면)

## 먼저 알아두기

다정다감은 **웹사이트 앱이 아닙니다.**  
**리액트 네이티브(React Native) + 엑스포(Expo)**로 만드는 **아이폰용 모바일 앱**입니다.

개발 중에 화면을 확인하는 방법은 두 가지입니다.

| 방법 | 무엇인가요? | 우리가 쓰는가? |
| --- | --- | --- |
| **Expo Go (추천)** | 아이폰에 설치하는 무료 미리보기 앱 | ✅ **이게 정석** |
| 웹 브라우저 | 컴퓨터 크롬에서 대충 확인 | ❌ 제품 목표가 아님 (개발자 임시용) |

이전에 웹 화면이 보였던 이유는, 클라우드(Cloud) 개발 환경에 실제 아이폰이 없어서 **임시로 웹으로만 확인**했기 때문입니다.  
정빈님 아이폰에서는 **앱처럼** 보시면 됩니다.

---

## 준비물 (모두 무료)

1. 아이폰
2. 컴퓨터 (프로젝트 폴더가 있는 Mac/Windows)
3. App Store의 **Expo Go** 앱
4. 아이폰과 컴퓨터가 **같은 Wi-Fi**에 연결

> 비용: Expo Go로 미리보기 = **무료**  
> App Store에 정식 출시는 나중에 Apple 개발자 등록(유료)이 필요합니다. 지금은 하지 않습니다.

---

## 단계별 실행

### 1단계. 컴퓨터에서 프로젝트 열기

터미널(Terminal)에서 프로젝트 폴더로 이동합니다.

```bash
cd 프로젝트경로/dajungwalk
npm install
```

### 2단계. 개발 서버 켜기

```bash
npm start
```

잠시 후 터미널에 **QR 코드**가 나타납니다.

### 3단계. 아이폰에 Expo Go 설치

1. App Store 실행
2. `Expo Go` 검색
3. 설치 (무료)

### 4단계. QR 코드 스캔

1. 아이폰 기본 **카메라** 앱을 엽니다.
2. 컴퓨터 화면에 뜬 QR 코드를 비춥니다.
3. `Expo Go에서 열기`를 누릅니다.
4. 다정다감 역할 선택 화면이 **아이폰 앱 화면**으로 보이면 성공입니다.

### 같은 Wi-Fi가 안 될 때

같은 와이파이가 어렵다면 터널(Tunnel) 모드를 쓸 수 있습니다.

```bash
npx expo start --tunnel
```

- 보통 **무료**로 쓸 수 있습니다.
- 다만 Expo 계정 로그인이나 네트워크 제한이 있을 수 있어, 문제가 생기면 알려 주세요.
- 외부 서비스이므로 **쓰기 전에 한 번 더 확인**하겠습니다.

## 아직 “앱스토어 앱”은 아닙니다

| 단계 | 설명 | 비용 |
| --- | --- | --- |
| 지금 | Expo Go로 개발 중 앱 미리보기 | 무료 |
| 나중 | App Store에 정식 등록·출시 | Apple Developer 연간 약 $99 |

지금은 **아이폰 앱 화면으로 확인**하는 단계이고, 스토어 출시는 4차·출시 단계에서 다시 안내합니다.

## 자주 하는 오해

**Q. 지금 만든 게 웹페이지인가요?**  
A. 아니요. 코드는 아이폰 앱용입니다. 웹은 임시 확인용일 뿐입니다.

**Q. 아이폰에서 보려면 Mac이 꼭 필요한가요?**  
A. Expo Go로 미리볼 때는 Mac이 없어도 됩니다. (Windows 컴퓨터 + 아이폰으로 가능)

**Q. Xcode가 필요한가요?**  
A. 지금은 필요 없습니다. 스토어 출시·일부 네이티브 빌드 단계에서만 필요할 수 있습니다.
