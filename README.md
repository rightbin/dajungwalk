# 다정다감 (Dajungdagam)

초등학생의 **학교 → 학원 동행**을 부모와 도우미가 안전하게 연결하는 서비스입니다.  
(기존 기획명: 다정걸음 / 저장소 이름: `dajungwalk`)

**초기 운영 지역:** 경기도 안양시 평촌·범계  
**개발 대상:** **iPhone 앱** (웹사이트 아님)

> 이 프로젝트는 웹페이지가 아니라 **아이폰용 모바일 앱**입니다.  
> 화면 확인은 아이폰의 **Expo Go**로 하세요.  
> 자세한 방법: [docs/아이폰에서_보는_방법.md](./docs/아이폰에서_보는_방법.md)

## 이 프로젝트가 쓰는 기술

| 한국어 설명 | 영어 원문 | 역할 |
| --- | --- | --- |
| 엑스포 | Expo | 스마트폰 앱을 쉽게 만들고 실행하는 도구 |
| 리액트 네이티브 | React Native | 아이폰·안드로이드 앱을 JS/TS로 만드는 프레임워크 |

## 개발 원칙

1. 추가 유료 프로그램·구독 서비스를 쓰지 않습니다.
2. 가능한 모든 작업은 무료 도구로 진행합니다.
3. AI를 최대한 활용해 개발합니다.
4. 초보자도 따라올 수 있게 단계별로 설명합니다.
5. 기존 구조를 먼저 파악하고, 임의로 파일을 바꾸지 않습니다.
6. 아이폰에서 쓸 수 있는 앱을 목표로 합니다.
7. **비용이 생길 수 있는 작업은 반드시 미리 알립니다.**
8. 요구사항정의서의 **미확정 사항은 임의로 결정하지 않습니다.**

## 실행 방법 (아이폰 앱으로 보기)

웹 브라우저가 아니라 **아이폰 화면**으로 확인하는 것이 기본입니다.

### 1단계. 의존성(Dependencies) 설치

```bash
npm install
```

### 2단계. 개발 서버(Development Server) 시작

```bash
npm start
```

터미널에 QR 코드가 나옵니다. (`w`를 눌러 웹을 열 필요는 없습니다.)

### 3단계. 아이폰 Expo Go로 열기 (무료)

1. App Store에서 **Expo Go**를 설치합니다.
2. 아이폰과 컴퓨터를 **같은 Wi-Fi**에 연결합니다.
3. 아이폰 카메라로 QR 코드를 스캔 → Expo Go에서 엽니다.
4. 「다정다감」 역할 선택 화면이 **앱처럼** 보이면 성공입니다.

더 자세한 설명: [docs/아이폰에서_보는_방법.md](./docs/아이폰에서_보는_방법.md)
