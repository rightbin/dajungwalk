# 다정걸음 (Dajung Walk)

아이폰(iPhone)에서 사용할 수 있는 모바일 앱을 **무료 도구**로 만드는 프로젝트입니다.

## 이 프로젝트가 쓰는 기술

| 한국어 설명 | 영어 원문 | 역할 |
| --- | --- | --- |
| 엑스포 | Expo | 스마트폰 앱을 쉽게 만들고 실행하는 도구 |
| 리액트 네이티브 | React Native | 아이폰·안드로이드 앱을 자바스크립트/타입스크립트로 만드는 프레임워크 |
| 타입스크립트 | TypeScript | 코드에 타입을 붙여 실수를 줄이는 언어 |
| 엑스포 고 | Expo Go | 아이폰에 설치해 개발 중인 앱을 바로 보는 무료 앱 |

## 개발 원칙

1. 추가 유료 프로그램·구독 서비스를 쓰지 않습니다.
2. 가능한 모든 작업은 무료 도구로 진행합니다.
3. AI를 최대한 활용해 개발합니다.
4. 초보자도 따라올 수 있게 단계별로 설명합니다.
5. 기존 구조를 먼저 파악하고, 임의로 파일을 바꾸지 않습니다.
6. 아이폰에서 쓸 수 있는 앱을 목표로 합니다.
7. **비용이 생길 수 있는 작업은 반드시 미리 알립니다.**

## 비용 안내 (중요)

| 단계 | 비용 |
| --- | --- |
| 지금(프로젝트 만들기·코드 작성) | **무료** |
| 아이폰에서 Expo Go로 미리보기 | **무료** |
| 앱 스토어(App Store)에 정식 출시 | **유료** — Apple Developer Program 연간 약 $99 (나중에 출시할 때 다시 안내) |
| EAS Build 등 클라우드 빌드 | 무료 할당량이 있으나, 한도를 넘으면 유료일 수 있음 → **사용 전에 반드시 안내** |

지금은 출시하지 않고, **로컬 개발 + Expo Go 미리보기**만 사용하므로 비용이 들지 않습니다.

## 폴더·파일 구조 (초보자용)

```
dajungwalk/
├── App.tsx          # 앱의 첫 화면 코드
├── index.ts         # 앱을 시작하는 진입점(Entry Point)
├── app.json         # 앱 이름, 아이콘 등 설정
├── package.json     # 프로젝트 이름과 사용할 패키지 목록
├── tsconfig.json    # TypeScript 설정
├── assets/          # 아이콘·이미지 등 정적 파일
└── README.md        # 이 설명 문서
```

## 실행 방법 (단계별)

### 1단계. 의존성(Dependencies) 설치

터미널에서 프로젝트 폴더로 이동한 뒤:

```bash
npm install
```

### 2단계. 개발 서버(Development Server) 시작

```bash
npm start
```

터미널에 QR 코드가 나타납니다.

### 3단계. 아이폰에서 보기 (무료)

1. App Store에서 **Expo Go** 앱을 설치합니다. (무료)
2. 같은 Wi-Fi에 연결된 아이폰으로 QR 코드를 스캔합니다.
3. 다정걸음 첫 화면이 보이면 성공입니다.

> Mac이 없어도, `npm run ios`(Xcode 필요) 없이 Expo Go만으로 아이폰 테스트가 가능합니다.
